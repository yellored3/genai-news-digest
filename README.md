# genai-news-digest

`naver-news` Claude Code 스킬이 매일 자동 발행하는 생성형 AI 업계 뉴스 인사이트 뉴스레터 아카이브입니다.

- 라이브 페이지: https://yellored3.github.io/genai-news-digest/
- 뉴스레터 본체는 `{YYYY-MM}/{YYYYMMDD}.html`, 인사이트 요약 아카이브는 `archive/{YYYYMMDD}.json`에 쌓입니다.
- 원본 스킬 소스: [fastcampus-cc 저장소](https://github.com/yellored3/fastcampus-cc)의 `50-my-work/Part06-스킬만들기/실습27-검색API스킬/skill-source/`
